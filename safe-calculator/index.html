🧮 Safe Calculator

A calculator that never crashes: it catches mistakes instead. Every calculation runs through guard clauses that turn silent bugs into friendly, readable error messages.

What makes it "safe"?

  • Rejects anything that isn't a real number, on both fields, before doing any math.
  • Blocks division by zero with a clear explanation instead of returning Infinity.
  • Wraps every calculation in a try / catch, so an unexpected input can never crash the page.
