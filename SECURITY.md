# Security Policy

## Reporting a vulnerability

Please report security problems privately rather than in a public issue.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability** and describe what you found.

You can expect a reply as soon as the maintainer is able. Please do not share details publicly until the issue is resolved.

## Scope

This repository holds a static website and learning projects. The website stores no accounts, payments or personal data. The contact form opens the visitor's own email app and sends nothing to a server.
