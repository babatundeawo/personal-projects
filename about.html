About

Why this repo exists.

A personal coding workspace where every new idea starts small and gets rebuilt until it holds up to real use.

This is my personal coding workspace, the place every new project starts as a small learning exercise and gets rebuilt until it holds up to real use. Each build in the log is a complete, working page: open it, try it, break it, read the source. Nothing here depends on a framework or a build step unless the project explicitly calls for one.

I keep this repository as my default workspace in VS Code, so expect it to keep growing; new projects get added directly as new folders, whenever they're ready, with no category to sort them into first. Right now that's {{N_PROJECTS}} projects: a few polished standalone builds, a couple of "same brief, five independent attempts" comparisons, a growing AI agent bootcamp, and well over a hundred smaller Python and web-development exercises, each still just its own folder.

The goal isn't to reach for a framework by default. It's to get genuinely comfortable with HTML, CSS and JavaScript first, so that when a framework does earn its place in a project, I'm reaching for it on purpose, not out of habit.

How I work

A few working principles

  • 01

    Ship the whole thing

    A build isn't done until it's usable end to end, edge cases included.

  • 02

    Frameworks are a choice

    Reach for one when it earns its place, not by default.

  • 03

    Accessible by default

    Keyboard support and clear focus states aren't an afterthought.

  • 04

    Document as you go

    Every build gets a README that explains the decisions, not just the code.
