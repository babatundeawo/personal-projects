Install Build Log

Add it to your home screen. It opens full screen and works without internet.

Install on iPhone or iPad

Safari on iPhone has no install button, so it takes three taps:

  1. Tap the Share button in Safari's toolbar (a square with an arrow pointing up).

  2. Scroll down and tap Add to Home Screen.

  3. Tap Add. Build Log now sits on your home screen like any other app.

Not seeing Share? Open this page in Safari, not inside another app's browser.
