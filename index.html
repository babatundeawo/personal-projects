Process

          
How each entry gets built

          

            The same four-step loop, every time, whether it takes an
            afternoon or a week.
          

        

        

          

            
01

            
Pick a real problem

            
Something small and concrete enough to finish, not a toy.

          

          

            
02

            
Build from scratch

            
No frameworks by default. Reach for HTML, CSS and JS first.

          

          

            
03

            
Handle the edge cases

            
Bad input, empty states, small screens: all treated as normal.

          

          

            
04

            
Ship and document

            
A working page, a clean README, and code that reads back well.
