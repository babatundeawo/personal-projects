About

          
Why this repo exists

          

            This is my personal coding workspace — the place every new
            project starts as a small learning exercise and gets rebuilt
            until it holds up to real use. Each build in the log above is a
            complete, working page: open it, try it, break it, read the
            source. Nothing here depends on a framework or a build step
            unless the project explicitly calls for one.
          

          

            I keep this repository as my default workspace in VS Code, so
            expect it to keep growing — new builds get added to the log as
            they're finished.
