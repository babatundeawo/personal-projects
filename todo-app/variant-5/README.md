# 🚀 My To-Do List Application

A modern, responsive To-Do List web application built with pure HTML, CSS, and JavaScript (ES6). Perfect for learning frontend development, DOM manipulation, and Local Storage.

## ✨ Features

- ➕ **Add Tasks** – Type a task and click Add or press Enter
- ✏️ **Edit Tasks** – Double-click text or click the edit icon
- ❌ **Delete Tasks** – Remove individual tasks
- ✅ **Mark as Completed** – Toggle completion status
- 🔍 **Search Tasks** – Instantly filter by keyword
- 📂 **Filter** – All / Active / Completed views
- 💾 **Local Storage** – Tasks persist after refresh
- 🌙 **Dark Mode** – Toggle light/dark theme
- 📊 **Live Stats** – Total, completed, and pending counts
- 🧹 **Clear Completed** – Remove all finished tasks at once
- 🗑️ **Delete All** – Clear the entire list
- 📱 **Fully Responsive** – Works great on mobile
- 🚫 **Duplicate Prevention** – Blocks identical tasks
- ⌨️ **Keyboard Support** – Enter to add, Enter/Esc while editing

## 🚀 How to Run

1. Open `index.html` in any modern browser
2. Or serve with a local server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
