# My To-Do List

A beginner-to-intermediate To-Do List application built with HTML5, CSS3 and vanilla JavaScript.

## Features

- Add tasks
- Prevent empty tasks
- Prevent duplicate tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter by All / Active / Completed
- Task statistics
- Clear completed tasks
- Delete all tasks
- Save tasks with Local Storage
- Keyboard support through the form's Enter key
- Responsive mobile design
- Light/dark mode

## Project Structure

```text
todo-app/

└── icons/
```

## How to Run

No build tools or dependencies are required.

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Start adding tasks.

For the best development experience, open the folder in VS Code and use the Live Server extension.
