FAQ

Before you reach out

Are these projects open source?

Yes. Every build lives in the public repository, with its own README covering how it works and why it was built that way.

Can I reuse the code?

Check the repository for licensing details. In general, these are learning-focused builds meant to be read, forked, and adapted.

Do you take on freelance or contract work?

Send a message with a bit of detail about the project and timeline, and I'll get back to you as soon as I can.

I found a bug in one of the builds, where do I report it?

Open an issue on the relevant folder in the GitHub repository, or send a message through this form with a description of what went wrong.
