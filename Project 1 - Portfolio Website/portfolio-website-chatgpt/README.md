# Babatunde Portfolio Website

A fully responsive beginner-to-professional portfolio built with plain HTML5, CSS3 and JavaScript.

## Included
- Responsive home, about, skills, projects, resume and contact sections
- Mobile navigation menu
- Dark/light mode toggle with localStorage
- Scroll reveal animations
- Contact form validation/demo feedback
- Project cards with placeholder artwork
- Downloadable sample `resume.pdf`

## Run locally
Open `index.html` directly in a browser, or use a simple local server.

Example with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Upload the folder to GitHub Pages, Netlify, or Vercel. No build step is required.

## Customize
1. Replace the placeholder SVGs in `images/` with real project/profile images.
2. Replace `resume.pdf` with your actual resume.
3. Update social links and email in `index.html`.
4. Connect `contactForm` in `script.js` to a real backend/form service when ready.
