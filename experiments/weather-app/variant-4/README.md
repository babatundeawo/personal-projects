# Atmosphere Pro - Weather Application

An upgraded, production-ready Weather Application built with HTML5, CSS3, and modern Vanilla JavaScript (ES6+).

## Features
- **Real-Time Weather Data**: Temperature, Humidity, Wind Speed & Direction, Pressure, Visibility, Sunrise & Sunset times.
- **5-Day Weather Forecast**: Daily forecast grid powered by the OpenWeatherMap 5-day API.
- **Geolocation Support**: Instantly detect location weather via Browser Geolocation API.
- **Dynamic Background Themes**: Visual themes that adapt to current weather conditions (Clear, Rain, Clouds, Snow).
- **Dark / Light Mode**: Interactive toggle for seamless day/night viewing.
- **Unit Converter**: Toggle dynamically between Celsius (°C) and Fahrenheit (°F).
- **Recent Search History**: Saves recent city queries locally in `localStorage`.

## Setup Instructions
1. Open `script.js`.
2. Replace `const API_KEY = "YOUR_API_KEY_HERE";` with your actual free API key from [OpenWeatherMap](https://openweathermap.org/api).
3. Open `index.html` in any browser to test and run!
