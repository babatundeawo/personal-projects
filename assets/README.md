# assets

Shared styles, scripts and data for the site pages in the repository root.

| Path | Used by |
| --- | --- |
| `css/site.css`, `js/site.js` | All site pages: design tokens, header, footer, buttons, theme, motion |
| `css/home.css`, `js/home.js` | Home page and 404 page |
| `css/projects.css`, `js/projects.js` | Projects page (search and filters) |
| `css/about.css` | About page |
| `css/contact.css`, `js/contact.js` | Contact page (form and copy-email) |
| `css/base.css`, `css/portfolio-nav.css`, `js/portfolio-nav.js`, `js/animations.js` | Shared styles and scripts for the `safe-calculator`, `smart-form-validator` and `student-report-card` projects and the ecommerce live demo |
